# SalesCost Pro

Bản web tĩnh hoàn chỉnh, toàn bộ CSS và JavaScript nằm trong `index.html` để tránh lỗi thiếu asset.

## Chạy thử
Mở trực tiếp `index.html` trong trình duyệt.

## Deploy Vercel
- Framework Preset: Other
- Build Command: `npm run build`
- Output Directory: `dist`
- Root Directory: để trống

Upload các file bên trong thư mục này lên thư mục gốc GitHub, không upload cả thư mục lồng bên ngoài.
