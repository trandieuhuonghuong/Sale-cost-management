# SalesCost Pro – cập nhật module Thương mại điện tử

Bản này giữ nguyên toàn bộ chức năng hiện có và chỉ bổ sung module **Thương mại điện tử** với 2 tab:

- **Kế hoạch**: theo sàn, kỳ, mục tiêu doanh thu, số đơn, ROAS và ngân sách theo hạng mục.
- **Thực thi**: theo dõi ngân sách, chi phí đã dùng, doanh thu thực tế, số đơn, AOV, ROAS và cảnh báo ngân sách.

## Deploy Vercel
- Framework Preset: Other
- Build Command: `npm run build`
- Output Directory: `dist`
- Root Directory: để trống
