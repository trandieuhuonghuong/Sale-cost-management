# SalesCost Pro – Vercel Complete

Bản web tĩnh đầy đủ cho hệ thống quản lý Doanh thu, Chi phí và Tài liệu.

## Chạy thử trên máy

```bash
npm run build
npx serve dist
```

## Thiết lập Vercel

- Framework Preset: Other
- Root Directory: để trống
- Build Command: npm run build
- Output Directory: dist
- Install Command: để mặc định

Sau khi deploy, vào Settings > Domains và xác nhận domain đang trỏ tới deployment Production mới nhất.
